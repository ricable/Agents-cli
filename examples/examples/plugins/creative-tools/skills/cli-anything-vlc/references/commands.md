# Command Reference — cli-anything-vlc

## playback

### `playback-list`

list playback

**Arguments:**
  - `--id` (string) — playback identifier

### `playback-create`

create playback

**Arguments:**
  - `--id` (string) — playback identifier

### `playback-get`

get playback

**Arguments:**
  - `id` (string, required) — playback identifier

### `playback-update`

update playback

**Arguments:**
  - `id` (string, required) — playback identifier

### `playback-delete`

delete playback

**Arguments:**
  - `id` (string, required) — playback identifier
