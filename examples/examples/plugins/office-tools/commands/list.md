# office-tools tools

This plugin provides 2 tools:

- **cli-anything-drawio**: Use when creating diagrams, managing shape, managing connection in Draw.io. Do NOT use for manual GUI interaction or unsupported Draw.io plugins. Wraps Draw.io, lxml via subprocess backend.
- **cli-anything-libreoffice**: Use when editing documents, managing spreadsheet, managing presentation in LibreOffice. Do NOT use for manual GUI interaction or unsupported LibreOffice plugins. Wraps LibreOffice, python-docx, openpyxl via subprocess backend.
