# Command Reference — cli-anything-zoom

### `meeting-list`

**Arguments:**
  - `--id` (string) — meeting identifier

**Arguments:**
  - `--id` (string) — meeting identifier

### `meeting-get`

**Arguments:**

### `meeting-update`

update meeting

**Arguments:**
  - `id` (string, required) — meeting identifier

### `meeting-delete`

**Arguments:**
  - `id` (string, required) — meeting identifier
